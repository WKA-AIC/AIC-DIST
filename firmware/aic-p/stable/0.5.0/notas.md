# AIC-P 0.5.0

Publicado em 2026-09-13 · canal: stable

Build gerada a partir da branch `legacy-v0.5` (commit `f5cf1d7`) do
repositório AIC-P-FW, com `PROJECT_VER` fixado em `0.5.0` para esta
publicação. Versão de produção mantida para compatibilidade com
equipamentos AIC-DS anteriores ao rompimento do protocolo CAN legado -
não é uma versão de teste, é a linha estável correspondente a essa
geração de hardware/driver.

## Atenção
- Sem suporte a Wi-Fi/OTA - atualização só via UART.
- Movida de `beta` para `stable` em 2026-09-13: é uma versão de
  produção válida para o parque de equipamentos que ainda usa a
  revisão `legacy-v0.5`, não uma versão de teste mais antiga que a
  `1.0.0`.
